# Hackathon packing list

Running list of physical kit to bring to the hackathon weekend. Add
items as they come up; tick off when packed.

## Cables / power

- [ ] **Multiway USB cable** (single trunk -> USB-C / micro-USB / Lightning
      tails). Lets one plug power any of the dev boards / phones at
      the bench when sockets are scarce.
- [ ] **USB-C to micro-USB cables** (x2). For the Heltec ESP32 boards,
      whose micro-USB port talks to a phone's USB-C port for
      on-the-go flashing / serial.
- [ ] USB-C to USB-C cables (x2)
- [ ] USB-A to USB-C cables (x2)
- [ ] Mains adaptor / power bank
- [ ] USB hub (4+ port, powered)

## Boards / hardware

- [ ] ON8CIT WebRadio unit(s)
- [ ] Heltec ESP32 board(s)
- [ ] Spare batteries (Li-ion 18650 or whatever the Heltec takes)
- [ ] Antenna(s) for the Heltec LoRa radio

## Tools

- [ ] Laptop + charger
- [ ] Multimeter
- [ ] Screwdriver set (small Phillips + Torx for cases)
- [ ] Tweezers
- [ ] Soldering iron + solder + flux *(if reflow is plausible)*

## Misc

- [ ] Phone(s) with mobile hotspot enabled (WPA2, 2.4 GHz; some
      networks at the venue may block IoT clients)
- [ ] Headphones / aux speaker for audio test
- [ ] Notebook + pen
- [ ] Stickers / labels
