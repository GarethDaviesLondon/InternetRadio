== Changes made in the latest round (22/23-4-2026) ==============================

  1. Deep sleep + L+R reboot now work.
     - SLEEP now fires on clean RELEASE of a Left-only press (was firing
       on press, which raced the reboot combo). R held at any time while
       L is down latches a "combo seen" flag so sleep is suppressed.
     - Right-button volume events are also suppressed while Left is held
       so the combo doesn't spam volume changes.
     - powerDeepSleep() now enables the RTC pull-up on GPIO 0 and puts
       the pin in RTC mode before enabling ext0 wake. Without this the
       pin floats in deep sleep and wake was either instant or never.

  2. "Last joined" mark in `wifi list`.
     - netLastJoinedSlot() records the slot that succeeded (-1 until
       netConnect returns true). `wifi list` shows a leading ' *' and
       trailing "[joined]" on that slot so it's obvious which of several
       saved networks is the active one.

  3. mDNS heartbeat.
     - web.cpp re-calls MDNS.end() + MDNS.begin(hostname) every 30 s
       while WiFi is connected. If a router reboot / lease expiry had
       silently dropped the announcement, the next heartbeat brings it
       back without a reboot.

  4. Theme JSON (ini form, actually).
     - SD mount is wired up (real SD_MMC, 4-bit, pin map from Volos's
       sketch). If /theme.ini exists, displayLoadThemeFromSd() parses
       `key = value` lines and updates the Theme struct. Values accept
       `0xRRGGBB`, `0xXXXX` (RGB565 literal) or `R,G,B` decimal. No
       new lib_deps -- internet was patchy, so I avoided adding
       ArduinoJson for now. Keys: bg, orange, panelBg, panelBorder,
       volumeBar.

  5. Touch driver.
     - New touch.cpp scaffolds an XPT2046 resistive-touch driver behind
       -DUSE_TOUCH_XPT2046 build flag. Disabled by default because the
       Volos-reference Waveshare board is buttons-only. If your SKU has
       a touch overlay, flip the flag (and adjust TOUCH_CS / TOUCH_IRQ
       in config.h if the wiring is non-default) and the existing
       INPUT_TOUCH_TAP path activates.
     - For a GT911 (capacitive, I2C) variant: same API surface, different
       internal bus -- see the comment at the top of touch.cpp.

  6. Stations on SD.
     - stationsLoadFromSd() reads /stations.csv ("name,url" lines;
       '#'/';' starts a comment, CR stripped). Replaces the compiled
       preset list when at least one line parses. No web editor yet;
       for now edit the file on your PC and call `sd reload` from the
       CLI. The in-memory cap is 32 stations (kMaxStations in
       stations.cpp); tweak if you want more.

  7. Backlight dimming.
     - display.cpp tracks last-activity time; after 60 s of nothing the
       PWM duty drops from 110 to 20 (roughly 60 % -> 10 %). Any
       physical button, any CLI keystroke, and any connected web
       client wakes it back to full. Thresholds (kBacklightActive,
       kBacklightDim, kIdleDimMs) are named constants so a later theme
       file can override them without touching code.

  8. mDNS during AP provisioning.
     - provisionStart() now brings up on8cit-setup.local in AP mode
       alongside the existing DNSServer wildcard. LCD setup page also
       advertises the new URL. Phones that support Bonjour auto-route;
       others still see the captive-portal page via the wildcard.

  9. Finer volume.
     - Audio module stores raw 0..21 internally. audioSetVolume(1..5)
       still works (buttons + on-screen bar) and maps big-step to 4, 8,
       12, 16, 20. New audioSetVolumeRaw(0..21) is what the web slider
       uses.
     - NVS migration: any previously-saved "1..5 bucket" value is
       multiplied by 4 on load, so existing devices keep their volume
       feel after the update.

 10. 3-band EQ.
     - Web UI gets Bass / Mid / Treble sliders (each -40..+6 dB).
       Posts to POST /api/eq with b, m, t. The audio module calls
       s_audio.setTone() and persists the values to NVS. Restored on
       boot as part of audioRestoreSession().

 11. New CLI: `sd status`, `sd ls <path>`, `sd reload`.
     - Quick way to confirm the card mounted, browse it, and re-read
       stations.csv / theme.ini without a reboot.

All changes stayed inside the existing module boundaries; the only new
file is touch.cpp (off by default).


== Open / next up ===============================================================

Concrete follow-ups that would build naturally on what's in now:

A. Web-based station editor.
   - /stations page with add / remove / edit / drag-reorder; POST
     /api/stations persists back to /stations.csv on the SD card. The
     CLI + hardcoded-preset fallback stays for when the card is pulled.

B. Web-based WiFi management.
   - The CLI already has wifi add/remove/move/clear. Mirror that with
     /wifi on the web UI so the whole device is configurable from a
     phone.

C. Touch calibration.
   - If you populate the touch hardware, touch.cpp uses placeholder
     mapping (raw 300..3800 -> 0..239). A /touch_calibrate page that
     walks the user through 4 corner taps, then writes the measured
     min/max to NVS or /touch.ini on SD.

D. Theme hot-reload from the web UI.
   - Upload a theme.ini to SD via the web UI and call
     displayLoadThemeFromSd immediately; no reboot needed.

E. Recording.
   - Still deferred. Needs: a "tee" in the audio path that dumps the
     raw stream chunks to SD alongside an index sidecar, plus a
     /recordings web page. Would be a substantial piece of work.

F. Scrollable long SSID list in the AP portal.
   - The AP scan page works but in a busy WiFi environment it gets
     long. Add a search / filter input at the top.

G. Proper boot-screen logo.
   - Current logo is geometric (3 concentric rings + core dot). If you
     want a bitmap, drop a 32x32 or 48x48 RGB565 .h asset into
     winRadio/ and swap drawLogo() for a drawRGBBitmap call.

H. Battery-aware behaviour.
   - When the battery drops below ~3.2 V: warn on LCD, reduce backlight
     cap, or auto-sleep. Uses powerBatteryVolts() already.

I. State-push web UI.
   - Currently the web UI is one-shot (reload to see new song title /
     bitrate). A WebSocket at /ws pushing /api/state deltas every 500 ms
     would make the page feel like a real remote. Adds one dep
     (AsyncWebServer) -- consider once internet access is better.

J. Central theme + layout registry.
   - The Theme struct covers colours. Layout (panel positions, font
     sizes) is still hardcoded. A v2 would put layout offsets in the
     same struct so a /theme.ini can restyle more than just colours.
